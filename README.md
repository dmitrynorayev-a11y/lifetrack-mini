# Streaks — Habit Tracker

A **habit tracker** with a GitHub-style heatmap for every habit, current and
best streak counting, and one-tap "done today". Offline and private - your
habits stay in your browser.

**[Live demo](https://ansagan359.github.io/habit-tracker/)**

- Half-year heatmap per habit, laid out in week columns like GitHub
- Current streak and best streak, computed over the last year
- Mark / unmark today with one tap
- Multiple habits, add and delete freely
- localStorage persistence, zero dependencies

Run: open `index.html`. MIT license.
