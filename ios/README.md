# VYRA для iPhone · HealthKit

Нативная iOS-оболочка вокруг локальной RPG-версии приложения. В отличие от сайта GitHub Pages, эта сборка может запрашивать разрешение Apple Health и синхронизировать данные **без iOS «Команд»**.

## Что сделано
- SwiftUI-экран подключения Apple Здоровья с официальным системным запросом разрешений.
- Чтение шагов, сна, тренировок и дистанции ходьбы/бега через HealthKit.
- Автоматическое обновление при открытии/возврате в приложение и HKObserverQuery для фоновых событий (по усмотрению iOS).
- Локальный WKWebView со встроенной версией RPG-интерфейса VYRA. Данные передаются только в локальный HTML, не на удалённый веб-сайт.
- Оставлена возможность продолжить без разрешений.
- Apple не сообщает приложению, какие разрешения именно были отклонены. Поэтому отсутствие чисел **не следует** интерпретировать как отказ.

## Сборка
1. Нужен Mac с Xcode и [XcodeGen](https://github.com/yonaskolb/XcodeGen).
2. В каталоге ios/ выполнить \`xcodegen generate\` и открыть VYRA.xcodeproj.
3. В Signing & Capabilities выбрать вашу Apple Developer Team, сменить уникальный Bundle Identifier (например, com.example.vyra).
4. Проверить HealthKit capability и Background Delivery entitlement. Для установки на реальный iPhone потребуется подходящая подпись и provisioning profile; для распространения — TestFlight/App Store.
5. Выбрать реальный iPhone (не симулятор) и Run.
6. При первом запуске нажать «Подключить Apple Здоровье» и выбрать разрешения.

**Важное:** проект ещё не компилировался в Xcode в текущем окружении (нет macOS/iOS SDK). Потребуется финальная проверка сборки и реального HealthKit на iPhone.

## Данные и приватность
- HealthKit используется **только для чтения**, разрешение можно изменить в настройках iOS.
- Данные не отправляются на сервер. Локальный HTML встроен в приложение, внешние переходы WKWebView блокируются.
- XP считается по накопленным измерениям и квестам, сохранённым в локальном хранилище.
- HealthKit не гарантирует частоту фоновых обновлений; синхронизация при возврате в приложение надёжнее.
- Для пользователей без Apple Health и тех, кто отклонил запрос, есть ручной ввод.
